# YouTube chat availability repair — 2026-09-22

Two live sessions ended with `not_live` before receiving any chat. The player
endpoint could return HTTP 200 with `LOGIN_REQUIRED` and omit `videoDetails`,
while the next endpoint still returned an available public live chat.

The collector now uses a non-replay chat continuation to start live chat.
Absent player metadata alone no longer declares the broadcast ended. Unknown
availability uses the existing bounded reconnect policy. A replay response or
a confirmed non-live player without chat still ends live collection. Recorded
playback keeps its existing scheduler and resume contract.

Diagnostics distinguish an unknown live flag from false and record the player
status enum. Proxy endpoints, credentials, headers, bridge contracts, and app
configuration remain as before.

## Recorded startup follow-up

A subsequent recorded session failed before its first replay page because the
next response had no chat continuation. The same deployed page continued to
deliver 55 replay events for a known archive. The affected video's watch page
also omitted chat after the broadcast ended; the available evidence does not
establish whether replay was still being prepared or disabled.

Recorded startup previously treated one missing continuation as permanent
failure. It now uses the existing bounded reconnect delays (1, 2, 4, 8, 16
seconds), then reports `unavailable/reconnect_exhausted` if all six lookups lack
chat. A later successful lookup starts at the original requested offset. No
continuation is synthesized, and no authentication or proxy behavior changes.
This tolerates a transient missing response; it cannot restore a replay that
YouTube does not provide or guarantee readiness within this retry budget.

Validation: 94 collector tests pass, including real connection-effect cases
for missing-then-available replay with offset preservation, bounded exhaustion,
and immediately available public replay with an unavailable player. The first
two new cases fail against the preceding collector revision.
